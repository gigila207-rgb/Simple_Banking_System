
# 🏦 Simple Banking System

A beginner-friendly banking application built with Python.

## Features

- Check balance
- Deposit money
- Withdraw money
- Transaction history
- Modular project structure

## Project Structure

```
main.py     -> Runs the application
bank.py     -> Banking operations
data.py     -> Stores account information
utils.py    -> Helper functions
```

## Future Features

- Login system
- Multiple accounts
- JSON database
- GUI with Tkinter
